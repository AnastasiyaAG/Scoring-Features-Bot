# scoring-product-backlog
Скрипт на Python для валидации и подготовки продуктовых гипотез к отправке в ИИ

Проблема: 
В реальной разработке ИИ-сервисов продакт-менеджер часто сталкивается с проблемой: нейросети (LLM) очень капризны к формату входных данных. Если скормить им хаотичный бэклог, они выдадут плохой результат. Этот проект решает задачу предобработки данных (Data Preprocessing) — важнейшего этапа в любом AI-продукте.

Суть проекта: 
Я создала программу, которая берет бэклог продуктовых гипотез (из файла) и готовит их для отправки в нейросеть. Код проверяет каждую гипотезу на наличие обязательных полей , обрабатывает ошибки, если данных не хватает и упаковывает всё в идеальный JSON-формат, готовый для ИИ-модели.

Результат работы кода: 
На выходе — структурированный массив данных, отсортированный по приоритету.
