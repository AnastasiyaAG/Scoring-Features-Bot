# 📊 Scoring Features Bot (RICE + AI Product Manager)

Telegram-бот на Python для интерактивного сбора, валидации, RICE-скоринга и продуктовой аналитики бэклога спринта с использованием LLM (Groq API) и бизнес-контекста продукта.

## 💡 Идея и архитектура

Проект разделяет задачи между языковой моделью и детерминированным кодом на Python, чтобы исключить галлюцинации ИИ при математических расчетах, а также использует **Context Injection** (подключение вводных о продукте и команде из `context.md`) и **State Management** (управление диалогом):

1. **Интерактивный сбор и структурирование (LLM + Context → JSON):** Пользователь описывает идею фичи в свободной форме в Telegram. Если деталей недостаточно для точной оценки, модель `openai/gpt-oss-20b` задает 1–2 уточняющих вопроса с inline-кнопками (**«⏩ Оценить как есть»** и **«❌ Отмена»**). После получения ответа (или пропуска вопроса) ИИ сверяется с `context.md`, извлекает параметры (Reach, Impact, Confidence, Effort, требуемый стек) и сохраняет фичу в `backlog.json`.
2. **Валидация и скоринг (Python):** По команде `/score` запускается модуль `scorer.py`, который проверяет наличие обязательных полей, типы данных, корректность стека (`F`, `B`, `BaF`), защищает от деления на ноль, рассчитывает коэффициент **RICE** и сортирует задачи по убыванию приоритета в `scored_backlog.json`.
3. **Продуктовый анализ (JSON + Context → LLM):** По команде `/analyze` модель `openai/gpt-oss-120b` в роли Senior Product Manager анализирует отсортированный бэклог с учетом реальной емкости команды (состав разработчиков, QA, длительность спринта): выделяет Quick Wins, находит бутылочные горлышки по стекам и подсвечивает рискованные гипотезы.

## 🛠 Стек технологий

* **Язык:** Python 3.9+
* **Telegram Bot API:** `pyTelegramBotAPI` (команды меню, inline-клавиатуры, управление состояниями диалога)
* **LLM Интеграция:** `groq` (`openai/gpt-oss-20b` для диалога и JSON-экстракции, `openai/gpt-oss-120b` для продуктового ревью)
* **Конфигурация и безопасность:** `python-dotenv`, Markdown-контекст (`context.md`)

## 📂 Структура проекта

```text
├── main.py              # Точка входа: логика Telegram-бота, диалоги, кнопки и Groq API
├── scorer.py            # Модуль валидации данных, расчета формулы RICE и сортировки
├── context.md           # База знаний: вводные о продукте, MAU, составе команды и спринтах
├── backlog.json         # Накопительный бэклог текущего спринта (создается автоматически)
├── scored_backlog.json  # Отсортированный бэклог с рассчитанным RICE Score
├── .env                 # Секретные ключи API (не отслеживается Git)
├── .gitignore           # Исключения для Git
└── README.md            # Документация проекта
```

## 🚀 Установка и локальный запуск

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   git clone <ссылка-на-ваш-репозиторий>
   cd <папка-проекта>
   ```

2. **Установите зависимости:**
   ```bash
   pip3 install pyTelegramBotAPI groq python-dotenv
   ```

3. **Настройте переменные окружения:**
   Создайте файл `.env` в корне проекта и добавьте свои ключи:
   ```env
   TELEGRAM_TOKEN=ваш_токен_от_BotFather
   GROQ_API_KEY=ваш_ключ_от_GroqCloud
   ```

4. **Настройте контекст продукта:**
   Отредактируйте файл `context.md` под ваш продукт (укажите активную аудиторию, длительность спринта, состав команды и правила оценки Reach/Impact).

5. **Запустите бота:**
   ```bash
   python3 main.py
   ```

## 📱 Команды и сценарии работы

* **Любое текстовое сообщение** — запускает оценку новой фичи. Если описание слишком короткое, бот задаст уточняющий вопрос (можно ответить текстом, нажать **«⏩ Оценить как есть»** или **«❌ Отмена»**).
* `/score` — запускает валидацию, расчет RICE и выводит отсортированный рейтинг фичей.
* `/analyze` — формирует аналитический отчет и рекомендации по спринту от AI Product Manager.
* `/start` — выводит краткую инструкцию по работе с ботом.
